# Collage decor image credits

Every file in this folder is derived from a public-domain source. Each was
downloaded from Wikimedia Commons, then converted locally into a cream-ink
cutout: greyscale → invert → contrast-stretch → alpha = ink density, flat cream
RGB, trimmed and resized to ~300px. No AI generation was used.
